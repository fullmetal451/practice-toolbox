# 練琴工具箱

首頁提供和弦組成音練習與練琴循環播放器。

## 網站預覽和發布檔

- 在本資料夾執行 `npm run build:site`，會產生可直接放到靜態主機的 `dist/site/`。
- 本機預覽可執行 `python -m http.server 8765 --bind 127.0.0.1 --directory dist/site`，在瀏覽器開啟 [練琴工具箱](http://127.0.0.1:8765/)。
- 和弦練習與循環播放器分別在 `chords/` 與 `loop/`。循環播放器請透過 HTTP／HTTPS 開啟。
- 原本的 `npm run build` 仍會輸出可離線開啟的和弦練習器 `dist/index.html`。

## 練琴循環播放器

- 貼上 YouTube 連結或選擇本機音檔。播放時可按 A／B 標記，也可暫停後輸入秒數。
- 用拉桿選擇倍速。本機音檔每格 0.05 倍，YouTube 使用該影片支援的速度。手動填入原速 BPM 可查看實際播放速度換算後的 BPM。
- 可設定輪間等待、加速和預備拍。預備拍預設關閉，可選只在第一遍數，或每一遍都數。一拍一秒，共四拍。選「從頭再來」會重新開始第一遍，暫停後繼續會接著原位置播放。
- 最近練習和片段保留在目前的瀏覽器。可另外選擇保留音檔，方便下次直接開啟。

## 和弦組成音練習器

- 在設定頁選擇題型、每題時間、答題數（5、10、15、20 或 30 題）與要練習的和弦類型，按「開始練習」。
- 每個答案音使用單一格位顯示完整音名；格位上方的 `♯` 與下方的 `♭` 按鈕可切換升降記號。每個音只使用單一升或降記號。
- PC：點選音名格，或以 `←`、`→` 移動；`C` 至 `B` 不分大小寫，`+` 為升、`-` 為降。輸入下一個音名字母時，會自動前進到下一格。
- 訂正答案後，按 `Enter` 可前往下一題；最後一題則進入結算頁。
- 手機：使用畫面上的 C–B、`♭`、`♯` 按鍵輸入；這組按鍵同時也可在 PC 點選。
- 和弦類型依「和弦組成公式」表分為基本和弦、延伸和弦與變化和弦；預設勾選全部基本和弦。可依小類逐一挑選或全選，並可按「查看吉他指板音名」開啟標準調弦、第 1 至 12 格的對照圖。指板只標示自然音 C、D、E、F、G、A、B，並採 TAB 譜方向：最上方為高音 E。
- 送出或時間到後，可按「顯示吉他指板」查看本題組成音位置；只顯示組成音，根音以粗體外框標示。
- 每題訂正時會顯示該和弦的組成公式。最後一題訂正後可查看結算：正確率、答對／答錯題數，以及錯題的和弦、公式與組成音。

## 維護

在本資料夾執行：

```powershell
npm test
npm run build
npm run test:dist
npm run build:site
```

不需安裝套件；使用 Node.js 內建測試工具。
