# 練琴工具箱

首頁提供和弦組成音練習、練琴循環播放器、吉他指板音名練習、和弦指法查詢、換和弦練習、音階指板與節拍器。

## 網站預覽和發布檔

- 在本資料夾執行 `npm run build:site`，會產生可直接放到靜態主機的 `dist/site/`。
- 本機預覽可執行 `python -m http.server 8765 --bind 127.0.0.1 --directory dist/site`，在瀏覽器開啟 [練琴工具箱](http://127.0.0.1:8765/)。
- 和弦練習、循環播放器、指板音名、和弦指法、換和弦、音階指板與節拍器分別在 `chords/`、`loop/`、`fretboard/`、`voicings/`、`changes/`、`scales/` 與 `metronome/`。本網站請透過 HTTP／HTTPS 開啟。
- 原本的 `npm run build` 仍會輸出可離線開啟的和弦練習器 `dist/index.html`。

## 練琴循環播放器

- 貼上 YouTube 連結或選擇本機音檔。播放時可按 A／B 標記，也可暫停後輸入秒數。
- 用拉桿選擇倍速。本機音檔每格 0.05 倍，YouTube 使用該影片支援的速度。手動填入原速 BPM 可查看實際播放速度換算後的 BPM。
- 可設定輪間等待、加速和預備拍。預備拍預設關閉，可選只在第一遍數，或每一遍都數。一拍一秒，共四拍。選「從頭再來」會重新開始第一遍，暫停後繼續會接著原位置播放。
- 最近練習和片段保留在目前的瀏覽器。可另外選擇保留音檔，方便下次直接開啟。不需要的曲子可從「最近練習」移除，片段與保留的音檔會一起刪除；目前開啟中的曲子不能移除。
- 選用已儲存的片段後，改了設定要按「更新片段」才會保留。有未儲存的變更時會顯示提示；改選其他片段、換曲子或離開頁面前會先詢問。

## 和弦組成音練習器

- 在設定頁選擇題型、每題時間、答題數（5、10、15、20 或 30 題）與要練習的和弦類型，按「開始練習」。
- 每個答案音使用單一格位顯示完整音名；格位上方的 `♯` 與下方的 `♭` 按鈕可切換升降記號。每個音只使用單一升或降記號。
- PC：點選音名格，或以 `←`、`→` 移動；`C` 至 `B` 不分大小寫，`+` 為升、`-` 為降。輸入下一個音名字母時，會自動前進到下一格。
- 訂正答案後，按 `Enter` 可前往下一題；最後一題則進入結算頁。
- 手機：使用畫面上的 C–B、`♭`、`♯` 按鍵輸入；這組按鍵同時也可在 PC 點選。
- 和弦類型依「和弦組成公式」表分為基本和弦、延伸和弦與變化和弦；預設勾選全部基本和弦。可依小類逐一挑選或全選，並可按「查看吉他指板音名」開啟標準調弦、第 1 至 12 格的對照圖。指板只標示自然音 C、D、E、F、G、A、B，並採 TAB 譜方向：最上方為高音 E。
- 送出或時間到後，可按「顯示吉他指板」查看本題組成音位置；只顯示組成音，根音以粗體外框標示。
- 每題訂正時會顯示該和弦的組成公式。最後一題訂正後可查看結算：正確率、答對／答錯題數，以及錯題的和弦、公式與組成音。

## 吉他指板音名練習

- 看指板上的標記選音名。指板最上面是第 1 弦，第 0 格是空弦，作答後才在標記處顯示音名。預設第 0–12 格，可選第 0–24 格的範圍、出題弦、自然音／全部 12 音與音名顯示方式。
- 自由練習不限題數，測驗固定 20 題。可自訂每題限時與訂正後的進行方式。結算可查看正確率與錯題，並直接重練錯題。

## 吉他和弦指法查詢

- 可直接輸入 `Am7`、`F#m`、`D/F#`、`E5`（強力和弦）或 `C°`、`C+`、`Csus` 等常見寫法，也可從根音、和弦種類與最低音選擇。指法圖標出琴格、手指編號、空弦與不彈的弦。
- 試聽可快速刷奏、逐弦播放，或點選指定弦。分數和弦依指法的實際最低音比對。
- 吉他指法資料為 [chords-db](https://github.com/tombatossals/chords-db/tree/df06fa7b425cf5fd29485ff6591236b3557e3fac) 的固定版本。授權隨資料放在 `voicings/LICENSE-chords-db.txt`。

## 換和弦練習

- 從常用組合挑一組，或自己輸入 2–12 個和弦（例如 `C G Am F`，空白或逗號分隔，寫法同和弦指法查詢）。每個和弦可用 ‹ › 換成其他指法。
- 設定速度 30–200 BPM、每個和弦 1–8 拍、依序或隨機（不會連續出現同一個和弦），可先數一小節預備拍。
- 畫面同時顯示「現在」和「下一個」和弦的指法圖；換之前一拍，下一個和弦的框會亮起來。換和弦的那一拍節拍聲較高，節拍聲可關。
- 練習時盡量讓手機螢幕不關閉。PC 可用 `Space` 開始／停止、`↑`／`↓` 調速。不判斷彈奏是否正確，不保存設定。
- 指法圖與節拍聲分別和和弦指法查詢（`voicings/diagram.js`）、節拍器（`metronome/sound.js`）共用。

## 音階指板

- 音階：大調、自然小調、大調五聲、小調五聲、藍調；主音 12 個，黑鍵主音自動選升降記號較少的寫法（例如 D♭ 大調、C♯ 小調）。
- 範圍可看整個指板（0–12 格），或選一個把位：從第 6 弦上的音階音起算，五聲與藍調 4 格、七聲音階 5 格，只列出在第 12 格內的把位。預設從第 6 弦根音起；超過第 12 格時改從第 5 弦根音起。指板標示可切換音名、度數或只標根音，點音可試聽。
- 跟拍走音：在選定的把位裡由低到高、再由高到低，亮起現在和下一個要彈的位置。可設速度 30–200 BPM、每拍 1 或 2 個音、預備拍、節拍聲，以及同時播放音高。不判斷彈奏是否正確，不保存設定。
- PC 可用 `Space` 開始／停止、`↑`／`↓` 調速。

## 節拍器

- 速度 20–300 BPM，可用 − ＋、拉桿或直接輸入數字，也可連續點按「點按測速」，取最近幾下的平均速度。
- 拍號 2/4、3/4、4/4、6/8；細分可選八分音符、三連音或十六分音符。第一拍重音可關閉。6/8 每一聲是八分音符，第 1、4 拍較重，不另外細分。
- 自動加速：每幾小節加幾 BPM，到上限為止，停止後回到起始速度。播放中手動改速度，會從新的速度重新起算。
- 播放時盡量讓手機螢幕不關閉（瀏覽器支援時）。PC 可用 `Space` 開始／停止、`↑`／`↓` 調速、`T` 點按測速。不保存設定。

## 維護

在本資料夾執行：

```powershell
npm test
npm run build
npm run test:dist
npm run build:site
```

不需安裝套件；使用 Node.js 內建測試工具。
